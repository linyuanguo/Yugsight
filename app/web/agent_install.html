Yugsight 探针安装

探针运行在被扫描的机器上, 只向中心端发起一条出站连接, 不监听任何端口, 无需管理员权限。 协议版本 v{{PROTO}}约 {{SIZE}} MB

不确定选哪个? Windows 一般选 x64; Linux/macOS 用 uname -m 看架构 (x86_64→x64, aarch64/arm64→ARM64)。

2Windows: 双击即装即用

把下载的 yugsight-agent.exe 拷到目标机器, 双击运行 —— 自动安装到 C:\YugsightAgent、注册开机自启动, 按弹窗提示填写中心端地址即可上线。 连不上中心端时会再次弹窗: 可选 5 分钟 / 30 分钟 / 自定义时间后再提醒, 或直接退出探针。

3Linux / macOS: 命令行启动

拷到目标机器任意目录, 然后在该目录执行(已带上本中心的地址与节点密钥):
./yugsight-agent -center {{ADDR}} -token {{TOKEN}}
请勿公开分享本页面(页面内含节点密钥)。

4确认上线

  • 启动后回到中心端 探针管理 页, 节点应在数秒内出现在列表中(每 5 秒自动刷新)。
  • 从 Windows 访问格式为 http://<中心端IP>:{{UIPORT}}/app/ 的地址进入管理界面; 从 Linux/macOS 访问则替换为对应 IP/端口。
  • 探针日志在同目录的 yugsight-agent.log, 出问题先看它。

5常见问题

  • 提示"未配置中心端地址": Windows 双击会自动弹框补填; Linux 请确认命令带了 -center, 或配置文件里地址不为空。
  • 提示"密钥错误": 启动参数/配置里的 token 与中心端 probe.json 的 center.token 不一致(密钥可在中心端 探针管理 页复制)。
  • 连不上中心端: 目标机器需能出站访问 {{ADDR}}; 请检查防火墙/安全组是否放行了这条出站连接。Windows 上会弹框让你改地址或稍后提醒。
  • Windows 卸载: 双击安装目录 C:\YugsightAgent 里的 卸载探针.exe(自动停止探针 + 删除开机自启 + 删除安装目录); 也可手工: 结束 yugsight-agent.exe 进程、删除该目录、删除注册表项 HKCU\Software\Microsoft\Windows\CurrentVersion\Run\YugsightAgent。
