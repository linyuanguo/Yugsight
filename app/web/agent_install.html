2Windows: 双击即装即用

把下载的 yugsight-agent.exe 拷到目标机器, 双击运行 —— 自动安装到 C:\YugsightAgent、注册开机自启动, 按弹窗提示填写中心端地址即可上线。 连不上中心端时会再次弹窗: 可选 5 分钟 / 30 分钟 / 自定义时间后再提醒, 或直接退出探针。

3Linux / macOS: 命令行启动

手动方式: 需先在步骤 1 把对应平台的探针安装包下载下来, 再拷到(上传到)目标机器, 然后执行下面命令(已带上本中心的地址与节点密钥):
./yugsight-agent -center {{ADDR}} -token {{TOKEN}}
以上命令带的是当前中心端地址 {{ADDR}}。 若中心端 IP 变化(换网/VPN), 旧命令即失效 —— 重新打开本页复制命令(地址自动更新), 再到探针端重跑即可; Windows 探针连不上时也会弹窗让你改地址。
Linux 一键安装(无需手动下载/上传): 在目标机器上执行下面一行(root 权限), 脚本自动从中心端 Web 端口 {{UIPORT}} 下载探针、安装到 /usr/local/bin 并用 systemd 托管(开机自启 + 进程崩溃自动拉起), 地址与节点密钥已由中心端注入脚本, 无需手填。需要目标机器已装 curl 与 systemd(服务器标配)且能访问中心端。
curl -fsSLk https://{{ADDRHOST}}:{{UIPORT}}/api/v2/probe/agent/install.sh | bash
非 root 账号执行时, 把结尾的 bash 换成 sudo bash; macOS 无 systemd, 请用上面的手动方式。

4确认上线

  • 启动后回到中心端 探针管理 页, 节点应在数秒内出现在列表中(每 5 秒自动刷新)。
  • 从 Windows 访问格式为 https://<中心端IP>:{{UIPORT}}/app/ 的地址进入管理界面; 从 Linux/macOS 访问则替换为对应 IP/端口。
  • 探针日志在同目录的 yugsight-agent.log, 出问题先看它。

5常见问题

  • 提示"未配置中心端地址": Windows 双击会自动弹框补填; Linux 请确认命令带了 -center, 或配置文件里地址不为空。
  • 提示"密钥错误": 启动参数/配置里的 token 与中心端 probe.json 的 center.token 不一致(密钥可在中心端 探针管理 页复制)。
  • 连不上中心端: 目标机器需能出站访问 {{ADDR}}; 请检查防火墙/安全组是否放行了这条出站连接。Windows 上会弹框让你改地址或稍后提醒。
  • 中心端地址变了(换网/VPN 导致 IP 变化): 探针不会自动切换, 重新跑一次一键安装命令即可(地址自动更新为当前 IP, 旧服务的地址会被覆盖, 开机自启保留, 无需手改任何文件)。 手动部署的(无 systemd 环境)则用新地址重跑启动命令。
  • Windows 卸载: 双击安装目录 C:\YugsightAgent 里的 卸载探针.exe(自动停止探针 + 删除开机自启 + 删除安装目录); 也可手工: 结束 yugsight-agent.exe 进程、删除该目录、删除注册表项 HKCU\Software\Microsoft\Windows\CurrentVersion\Run\YugsightAgent。

Yugsight Probe Install

The probe runs on the machine being scanned, makes a single outbound connection to the center, listens on no port and requires no admin privileges. Protocol v{{PROTO}}~ {{SIZE}} MB

1Download the probe

Not sure which one? On Windows, x64 is usually right; on Linux/macOS check the architecture with uname -m (x86_64→x64, aarch64/arm64→ARM64).

2Windows: double-click to install

Copy the downloaded yugsight-agent.exe to the target machine and double-click it — it installs to C:\YugsightAgent, registers auto-start, and you just follow the dialog to enter the center address. If it cannot reach the center, the dialog reappears: be reminded again in 5 / 30 / custom minutes, or quit the probe.

3Linux / macOS: start from the command line

Manual: first download the probe package for your platform in step 1, then copy (upload) it to the target machine and run the command below (already includes this center's address and node token):
./yugsight-agent -center {{ADDR}} -token {{TOKEN}}
The command above uses the current center address {{ADDR}}. If the center IP changes (network switch/VPN), the old command stops working — reopen this page to copy the command (the address updates automatically), then re-run it on the probe host; on Windows a dialog also appears so you can change the address.
One-click install for Linux (no manual download/upload): run the single line below on the target machine (root required). The script downloads the probe from the center's Web port {{UIPORT}}, installs it to /usr/local/bin and runs it under systemd (auto-start + auto-restart on crash). The address and node token are already injected by the center — nothing to type manually. The target machine needs curl and systemd (standard on servers) and network access to the center.
curl -fsSLk https://{{ADDRHOST}}:{{UIPORT}}/api/v2/probe/agent/install.sh | bash
When running as a non-root account, replace the trailing bash with sudo bash; macOS has no systemd, use the manual method above.
Do not share this page publicly (it contains the node token).

4Verify it is online

  • Back on the center's Probe Management page, the node should appear in the list within seconds (auto-refresh every 5s).
  • Open the admin console at https://<center IP>:{{UIPORT}}/app/ (from Windows, or the corresponding IP/port from Linux/macOS).
  • The probe log is yugsight-agent.log in the same directory — check it first when something goes wrong.

5FAQ

  • "Center address not configured": on Windows the double-click flow prompts you to fill it in; on Linux make sure the command carries -center, or that the address in the config file is not empty.
  • "Wrong token": the token in the start parameters/config does not match the center's probe.json center.token (the token can be copied on the center's Probe Management page).
  • Cannot reach the center: the target machine must be able to make an outbound connection to {{ADDR}}; check that the firewall/security group allows this outbound connection. On Windows a dialog appears so you can change the address or be reminded later.
  • Center address changed (IP changed due to network switch/VPN): the probe does not switch automatically — just re-run the one-click install command (the address updates to the current IP automatically, the old service's address is overwritten, auto-start is preserved, no file needs to be edited). For a manual deployment (no systemd), re-run the start command with the new address.
  • Uninstall on Windows: double-click Uninstall probe.exe in the install directory C:\YugsightAgent (auto-stops the probe + removes auto-start + removes the install directory); or manually: end the yugsight-agent.exe process, delete that directory, and delete the registry key HKCU\Software\Microsoft\Windows\CurrentVersion\Run\YugsightAgent.
