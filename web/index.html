导入自定义漏洞规则

    
格式必须为 {"rules":[...]}: 每条规则必填 id / name / pattern / type,
      type 取 body(正则匹配响应体) / header(正则匹配响应头) / path(敏感路径探测);
      severity 可填 high / medium / low / info(缺省 info)。
      导入即生效(无需重启); 同 ID 时内置优先。
